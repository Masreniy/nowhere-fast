# Стиль кода

> Адаптировано из ECC `rules/common/coding-style.md` (MIT). Убраны требования,
> завязанные на TypeScript и сборку — у нас ванильный JS в браузере.

## Базовые принципы

**KISS** — самое простое решение, которое действительно работает. Ясность важнее находчивости.

**DRY** — повторяющаяся логика выносится в общий модуль. У нас это сейчас нарушено
трижды: CSS-токены, Supabase-клиент и функции загрузки продублированы в
`index.html`, `city.html` и `admin.html`.

**YAGNI** — не строим абстракции заранее. Сначала работающий вертикальный срез,
потом обобщение — когда повторение стало реальным, а не предполагаемым.

## Организация файлов

Много маленьких файлов лучше, чем мало больших:

- 200–400 строк — норма, 800 — мягкий потолок для исходника
- группировать по домену (город, маршрут, день), а не по типу файла
- общий код выносить в `assets/` — у нас уже есть `assets/css/app.css`,
  который создан, но **ни одной страницей не подключён**

## Обработка ошибок

- Обрабатывать явно на каждом уровне
- Пользователю — понятное сообщение, в консоль — технические детали
- Никогда не глотать ошибку молча
- Сообщение об ошибке не должно раскрывать внутренности (сейчас мы выводим
  `err.message` прямо в интерфейс — это надо пересмотреть)

## Валидация ввода

Проверять на границах системы:

- любой ввод пользователя — до обработки
- любые данные из Supabase — это тоже внешние данные, им нельзя доверять слепо
- быстро падать с понятной ошибкой

## Именование

- Описательные имена: имя говорит, что лежит внутри, без комментария
- Булевы значения читаются как утверждение (`isLoading`, `hasRoutes`)
- Никаких магических чисел — именованные константы

## Чего избегать

**Глубокая вложенность** — ранний возврат вместо лестницы `if`.

**Магические значения** — `'Гуанчжоу'` захардкожен как город по умолчанию и как
условие для тегов. Такие вещи выносятся в данные, а не живут в коде.

**Длинные функции** — больше 50 строк обычно значит, что внутри несколько
ответственностей.

## Чек-лист перед завершением работы

- [ ] Код читается без комментариев-объяснений
- [ ] Функции небольшие (<50 строк)
- [ ] Файлы сфокусированы (<800 строк)
- [ ] Нет вложенности глубже 4 уровней
- [ ] Ошибки обработаны
- [ ] Нет захардкоженных значений
- [ ] Нет отладочных `console.log`

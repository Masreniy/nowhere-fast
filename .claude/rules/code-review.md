# Ревью кода

> Адаптировано из ECC `rules/common/code-review.md` (MIT). Убраны ссылки на
> агентов-ревьюеров под языки, которых у нас нет (Go, Rust, Python), и требование
> зелёного CI — CI пока не существует.

## Когда ревьюим — обязательно

- После написания или изменения кода
- Перед любым коммитом в общую ветку
- При изменении кода, связанного с доступом к данным и с авторизацией
- При архитектурных изменениях

## Чек-лист

- [ ] Код читается и понятно назван
- [ ] Функции сфокусированы (<50 строк)
- [ ] Файлы цельные (мягкий потолок — 800 строк)
- [ ] Нет вложенности глубже 4 уровней
- [ ] Ошибки обработаны явно
- [ ] Нет захардкоженных секретов
- [ ] Нет отладочных `console.log`
- [ ] Изменение проверено вручную, проверка описана (см. `testing.md`)

## Триггеры обязательного security-ревью

Останавливаемся и зовём агента **security-reviewer**, если менялось:

- что-либо, связанное с доступом к данным и правами (RLS, Supabase Auth)
- обработка пользовательского ввода
- запросы к базе
- вставка данных в разметку (наш главный риск — XSS)

## Уровни серьёзности

| Уровень | Значение | Действие |
|---|---|---|
| CRITICAL | Уязвимость или потеря данных | **БЛОКИРОВАТЬ** — чинить до мержа |
| HIGH | Баг или существенная проблема качества | **ПРЕДУПРЕДИТЬ** — желательно починить до мержа |
| MEDIUM | Поддерживаемость | **К СВЕДЕНИЮ** |
| LOW | Стиль, мелочи | **ЗАМЕТКА** — необязательно |

## Что ловим в первую очередь

**Безопасность:** захардкоженные секреты, SQL-инъекции, XSS (неэкранированный
ввод), отсутствие проверки прав.

**Качество:** большие функции и файлы, глубокая вложенность, отсутствие
обработки ошибок, мутации вместо неизменяемых операций.

**Производительность:** N+1 запросы (у нас есть — `city.html` грузит дни и
активности в цикле), отсутствие пагинации, неограниченные выборки.

## Критерии решения

- **Approve** — нет CRITICAL и HIGH. Ревью без замечаний — нормальный результат.
- **Warning** — есть HIGH, мержить с осторожностью.
- **Block** — есть CRITICAL.

Не выдумывать замечания, чтобы «ревью выглядело серьёзным». Подробные правила
фильтрации ложных срабатываний — в `.claude/agents/code-reviewer.md`.

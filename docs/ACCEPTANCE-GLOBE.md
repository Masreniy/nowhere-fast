# Критерии приёмки: глобус как вход в продукт

**Статус**: Draft
**Ревизия**: 1
**Дата**: 2026-09-16
**Готовил**: Claude по заданию владельца

Скилл: `intent-driven-development`. Продуктовое «зачем» — в
[PRODUCT-BRIEF.md](PRODUCT-BRIEF.md), развилки — в [adr/](adr/README.md).

## Зачем

Сейчас посетитель попадает на список городов. Список не отвечает на первый
вопрос путешественника — **«куда вообще имеет смысл лететь отсюда»**. Глобус
отвечает: человек видит, где он сам, что рядом, а что на другой стороне
планеты, и выбирает страну или город глазами, а не по алфавиту.

Это вход в продукт, а не украшение. Выбор на глобусе ведёт на страницу города,
то есть в уже работающий инструмент сбора поездки (ADR-0007).

## Объём

**В объёме:**

- Страница глобуса как точка входа: вращение, приближение, выбор страны и города
- Справочник стран и городов **в базе**, а не в файле рядом с кодом
- Язык интерфейса как свойство **всего проекта**, а не одной страницы
- Точка отсчёта (откуда человек летит) как свойство **всего проекта**
- Настоящие положения Солнца, Луны и звёзд по времени и месту

**Вне объёма:**

- Потоковые тайлы карт вместо вшитого снимка (отдельное решение, см. ADR-0008)
- Перевод названий городов на 10 языков (справочник даёт только латиницу)
- Замена лендинга: глобус живёт отдельной страницей, `index.html` не трогаем
- Аккаунты, сохранение выбранной страны на сервере

| С `file://` работают `data:`-картинки в canvas и в WebGL | тот же замер |
| Справочник `all-the-cities` даёт только латинские написания | поле `altName` пусто у всех 135 233 записей |
| В базе 1 город, 50 мест, 2 авторских маршрута | запрос к базе 16.09.2026 |

## Ограничения от владельца

- Язык, гео и часовой пояс касаются **всего проекта**, а не первой страницы
- Страны и города живут **в базе**
- Организовать по правилам проекта, а не «вставить файл прототипа целиком»

## Разбор рисков

| Область | Применимо | Что обязаны сделать |
|---|---|---|
| Безопасность и приватность | да | Геолокация — только по явному разрешению, координаты не уходят никуда, кроме браузера. Весь вывод данных — через `NF.dom` |
| Данные и миграция | да | Аддитивная миграция; справочник не смешивается с продуктовыми `cities` |
| Внешние эффекты и стоимость | да | Лицензии всех источников названы и атрибутированы (ADR-0010) |
| Совместимость | да | `file://` для страницы глобуса ломается — это развилка, а не мелочь (ADR-0008) |
| Интерфейс и доступность | да | Без WebGL — понятный текст; `prefers-reduced-motion`; клавиатура |

## Критерии

### AC-001: глобус открывается и показывает планету

- **Сценарий:** браузер с WebGL, страница открыта по http
- **Действие:** загрузка страницы
- **Ожидается:** в течение 10 секунд виден освещённый шар с настоящей картой,
  терминатор дня и ночи соответствует текущему времени UTC
- **Не должно:** оставаться вечной заставки; в консоли не должно быть ошибок
  страницы (`pageerror`)
- **Проверка:** playwright-прогон, снимок экрана, счётчик ошибок консоли
- **Приоритет:** Required

### AC-002: без WebGL человек получает текст, а не чёрный экран

- **Сценарий:** `getContext('webgl')` возвращает `null`
- **Действие:** загрузка страницы
- **Ожидается:** заставка снята, показан заголовок и объяснение на языке
  интерфейса
- **Проверка:** playwright с подменой `getContext`
- **Приоритет:** Required

### AC-003: страна и город выбираются и ведут в продукт

- **Сценарий:** глобус загружен
- **Действие:** поиск по названию страны или города, выбор результата
- **Ожидается:** камера приближается к месту; открывается карточка; если у города
  есть запись в `cities`, в карточке есть переход на `city.html?id=<uuid>`
- **Не должно:** предлагать переход туда, где записи нет
- **Проверка:** playwright, проверка адреса ссылки
- **Приоритет:** Required

### AC-004: справочник приходит из базы

- **Сценарий:** страница глобуса
- **Действие:** загрузка
- **Ожидается:** страны и города запрошены у Supabase через `NF.api`;
  в репозитории нет файла со списком стран или городов
- **Не должно:** страница знать имена таблиц — только `NF.api`
- **Проверка:** чтение кода + сетевой лог playwright
- **Приоритет:** Required

### AC-005: язык переключается на всех страницах

- **Сценарий:** любая публичная страница
- **Действие:** выбрать другой язык в переключателе
- **Ожидается:** тексты интерфейса меняются без перезагрузки; выбор
  сохраняется и действует на других страницах проекта; `<html lang>` и
  направление письма обновляются
- **Проверка:** тест на `assets/js/i18n.js` + ручной проход по страницам
- **Приоритет:** Required

### AC-006: точка отсчёта общая для проекта

- **Сценарий:** человек разрешил геолокацию на любой странице
- **Действие:** перейти на другую страницу проекта
- **Ожидается:** точка отсчёта та же; расстояния и «лететь» считаются от неё
- **Не должно:** координаты отправляться на сервер
- **Проверка:** тест на `assets/js/origin.js`, сетевой лог
- **Приоритет:** Required

### AC-007: часовой пояс не даёт нелепых точек

- **Сценарий:** геолокации нет, часовой пояс `Pacific/Chatham`
- **Действие:** определение точки отсчёта
- **Ожидается:** либо острова Чатем, либо отказ и приглашение выбрать вручную;
  **не** Чатем в Англии
- **Проверка:** тест на `origin.js` с подменой пояса
- **Приоритет:** Required

### AC-008: вес страницы назван и измерен

- **Сценарий:** сборка
- **Действие:** замер отданных байтов
- **Ожидается:** бандл сторонних библиотек ≤ 1,2 МБ (gzip ≤ 330 КБ),
  текстуры ≤ 1,4 МБ, справочник из базы ≤ 400 КБ gzip
- **Проверка:** числа в отчёте сборки, сетевой лог playwright
- **Приоритет:** Important

### AC-009: атрибуция источников выведена и не убирается

- **Сценарий:** страница глобуса
- **Действие:** осмотр подвала
- **Ожидается:** названы NASA (снимок), Natural Earth (контуры),
  GeoNames (города, CC BY 4.0), OpenStreetMap (места, ODbL — уже есть)
- **Проверка:** чтение разметки
- **Приоритет:** Required

## Блокирующие решения

- [x] Бандл сторонних библиотек коммитится как артефакт — ADR-0008
- [x] Страница глобуса требует http, `file://` для неё не поддерживается — ADR-0008
- [x] Справочник живёт в отдельных таблицах, не смешиваясь с `cities` — ADR-0010

## Допущения (отменяются словом владельца)

- **A1.** Глобус — отдельная страница `globe.html`, а не замена лендинга
- **A2.** Десять языков интерфейса те же, что в прототипе: ru, en, zh, es, ar,
  hi, pt, fr, de, ja
- **A3.** Города справочника показываются латиницей, пока нет второго источника
  написаний. Это ограничение источника, а не выбор

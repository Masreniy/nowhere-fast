# Nowhere Fast

Планировщик путешествий. Боль не в том, что человек не знает, **что** посмотреть,
а в том, что он не знает, **в каком порядке** — и теряет дни на возвраты, крюки и простои.

## Статус: ранняя стадия

Честно, без маркетинга:

- **Планировщика ещё нет.** Связывания мест в маршрут — главного, ради чего проект
  затевался, — пока не существует. Сейчас сайт только показывает город и готовые
  авторские маршруты.
- **Данные появились.** В базе на 16.09.2026: 1 город (Гуанчжоу), **50 мест**
  с координатами и местными написаниями, 2 авторских маршрута (опубликован 1),
  3 дня, 12 активностей. Места взяты из OpenStreetMap.
- **Запись в базу закрыта для всех.** Политики RLS применены, а входа (Supabase Auth)
  нет, поэтому `admin.html` ничего не сохранит. Чтение при этом работает и публично.
  Наполнять базу можно через интерфейс Supabase.

Полный список открытого техдолга — в [CLAUDE.md](CLAUDE.md).

## Стек

- Чистый HTML/CSS/JS — без сборки и без фреймворка.
- Supabase через CDN-клиент `@supabase/supabase-js@2.116.0` (версия зафиксирована),
  запросы идут прямо из браузера.
- Публикация на GitHub Pages из `main`; npm нужен только для тестов.

## Как открыть локально

Открой `index.html` двойным щелчком — страницы работают и с `file://`, скрипты
подключены классическими тегами, а не модулями. Сборка не нужна.

Но: чтобы увидеть города, места и маршруты, нужен доступ в интернет — данные
страница берёт из Supabase на каждом открытии. Без сети увидишь пустые блоки
и сообщение об ошибке загрузки.

## Тесты

```
npm install && npm test
```

Сейчас 16 тестов: `tests/dom.test.js` проверяет экранирование данных (защиту
от возврата XSS), `tests/api.test.js` — слой доступа к данным. Сети тестам не нужно.

| `index.html` | Лендинг и список городов |
